   │   ├─→ Table Number

   │   └─→ Total Amount with Tax
   │
   ├─→ [Proceed to Payment]
   │   │
   │   └─→ Create Order (Status: "Pending Payment")

   │             items: [...],

5. PAYMENT GATEWAY (Modal)
   │
   ├─→ Payment Methods:
   │   ├─→ 📱 UPI (Google Pay, PhonePe, Paytm)
   │   ├─→ 💳 Credit/Debit Card
   │   ├─→ 🏦 Net Banking
   │   └─→ 💰 Digital Wallet
   │
   ├─→ [Pay Now] → Process Payment
   │   │
   │   ├─→ POST /api/payment/create-payment-intent

   │   └─→ Redirect to: /order/{orderId}
   │
   └─→ [Cancel] → Close Modal

6. ORDER TRACKING PAGE (/order/{orderId})

   ├─→ Poll Order Status (Every 10 seconds)

┌─────────────────────────────────────────────────────────────────────────────┐
│                      BACKEND API ENDPOINTS                                  │
└─────────────────────────────────────────────────────────────────────────────┘

AUTH ROUTES (/api/auth)
├─→ POST   /login           - User login (returns JWT token)
└─→ POST   /register        - User registration

MENU ROUTES (/api/menu)
├─→ GET    /                - Get all menu items
├─→ GET    /categories/list - Get all categories
├─→ GET    /category/:cat   - Get items by category
├─→ POST   /                - Create menu item [ADMIN]
├─→ PUT    /:id             - Update menu item [ADMIN]
└─→ DELETE /:id             - Delete menu item [ADMIN]

ORDER ROUTES (/api/orders)
├─→ POST   /                - Create new order (status: "Pending Payment")
├─→ GET    /:id             - Get order by ID
├─→ GET    /                - Get all orders (with filter)
├─→ PATCH  /:id/status      - Update order status [ADMIN]
└─→ GET    /table/:tableId  - Get orders for specific table

TABLE ROUTES (/api/tables)
├─→ GET    /                - Get all tables
├─→ GET    /:id             - Get table by ID
├─→ POST   /                - Create table (auto-generates QR code)
├─→ PUT    /:id             - Update table
└─→ DELETE /:id             - Delete table

QR ROUTES (/api/qr)
├─→ POST   /generate/:tableId  - Generate QR code for specific table
├─→ POST   /regenerate-all     - Regenerate all QR codes
└─→ POST   /scan               - Validate scanned QR code

PAYMENT ROUTES (/api/payment)
├─→ POST   /create-payment-intent  - Initialize payment (returns paymentId)
└─→ POST   /verify-payment         - Verify and complete payment
                                     └─→ Updates order to "Paid" & "Received"


┌─────────────────────────────────────────────────────────────────────────────┐
│                        DATABASE MODELS                                      │
└─────────────────────────────────────────────────────────────────────────────┘

USER MODEL
{
  username: String (unique, required)
  password: String (hashed, required)
  role: String (enum: ["admin", "staff"], default: "staff")
  createdAt: Date
}

MENU ITEM MODEL
{
  name: String (required)
  description: String (required)
  price: Number (required)
  category: String (required)
  imageUrl: String (required)
  isVeg: Boolean (default: true)
  isAvailable: Boolean (default: true)
  createdAt: Date
  updatedAt: Date
}

TABLE MODEL
{
  tableNumber: Number (unique, required)
  capacity: Number (required)
  isAvailable: Boolean (default: true)
  qrCode: String (Base64 data URL)
  createdAt: Date
  updatedAt: Date
}

ORDER MODEL
{
  tableId: ObjectId (ref: "Table", required)
  items: [
    {
      menuItemId: ObjectId (ref: "MenuItem")
      name: String
      quantity: Number
      price: Number
    }
  ]
  totalAmount: Number (required)
  status: String (enum: [
    "Pending Payment",
    "Received",
    "In Kitchen",
    "Ready",
    "Served"
  ], default: "Pending Payment")
  paymentStatus: String (enum: ["Pending", "Paid", "Failed"])
  paymentMethod: String (UPI, Card, Net Banking, Wallet)
  paymentId: String
  paidAt: Date
  createdAt: Date
  updatedAt: Date
}

┌─────────────────────────────────────────────────────────────────────────────┐
│                          QR CODE WORKFLOW                                   │
└─────────────────────────────────────────────────────────────────────────────┘

RESTAURANT SETUP:
1. Admin creates table → QR code auto-generated
2. Admin downloads/prints QR code
3. QR code placed on physical table

CUSTOMER USAGE:
1. Customer scans QR code with phone
2. QR contains: { tableId, tableNumber, restaurantUrl }
3. Browser opens menu page with table parameter
4. Table ID saved in cart context
5. Customer orders → Order linked to table
6. Kitchen receives order with table number

QR CODE DATA:
{
  "tableId": "673fcd7a1234567890abcdef",
  "tableNumber": 5,
  "restaurantUrl": "http://localhost:3000/menu?table=673fcd7a1234567890abcdef"
}

Encoding: JSON → Base64 → QR Code Image (300x300px)
Format: PNG Data URL (stored in MongoDB)
